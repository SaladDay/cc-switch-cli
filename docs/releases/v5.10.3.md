# CC Switch CLI v5.10.3

v5.10.3 is a patch release for configurable Skills storage and deployment, global outbound proxy settings, provider-template navigation, Android session usage, library embedding, and upstream-aligned Skills safety.

## Highlights

- Choose either CC Switch's managed Skills directory or `~/.agents/skills` as the single source of truth, with guarded migration of managed Skills between them.
- Choose symlink or copy deployment for enabled applications from the TUI; the CLI also exposes `cc-switch skills sync-method` and `cc-switch skills storage-location`.
- Configure one persistent HTTP, HTTPS, or SOCKS5 outbound proxy across supported network clients from the CLI or TUI.
- Select provider templates through a grouped picker instead of an overflowing horizontal chip row.
- Build the Rust library without CLI-only dependencies by disabling default features.
- Use session-usage synchronization on Android/Termux without the unsupported standard-library file-lock path.
- Keep Skills database state, managed files, app deployments, repository metadata, and backup/cloud restores aligned more reliably with upstream behavior.

## Upgrade

The database schema remains at v17, so no database migration is required.

Existing Skills storage and deployment settings do not change automatically. Switching storage locations moves only database-managed Skills and refuses to claim or overwrite conflicting unmanaged directories. No outbound proxy is saved by default. When no saved proxy exists, standard proxy environment variables remain effective; if none are set, requests go directly. A saved proxy takes precedence over those variables.

Built-in updater:

```bash
cc-switch update
```

Homebrew:

```bash
brew upgrade cc-switch-cli
```

macOS/Linux installer:

```bash
curl -fsSL https://github.com/SaladDay/cc-switch-cli/releases/latest/download/install.sh | bash
```
