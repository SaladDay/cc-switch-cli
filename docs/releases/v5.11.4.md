# CC Switch CLI v5.11.4

This release restores database compatibility with CC Switch desktop v4.0.33 (schema 26), adds managed ChatGPT account selection for Codex, and fixes configuration, proxy, session and terminal issues.

## Added

- **Codex / Official Accounts**: Select a managed ChatGPT account in the OpenAI Official provider form, or keep the native Codex login. Account activation preserves the previous native login and follows upstream credential ownership and refresh behavior. Includes [#550](https://github.com/SaladDay/cc-switch-cli/pull/550), fixing [#547](https://github.com/SaladDay/cc-switch-cli/issues/547).
- **Sponsors**: Add IPWO to the sixth README sponsor position across the English, Chinese and Japanese documentation.

## Changed

- **Claude / Configuration Editing**: Edit the complete Claude configuration, saving provider fields to the provider record and global settings to the live configuration, with conflict handling for external changes. Legacy Claude common snippets remain readable but are no longer merged at runtime or newly written. Includes [#536](https://github.com/SaladDay/cc-switch-cli/pull/536), addressing [#530](https://github.com/SaladDay/cc-switch-cli/issues/530).
- **Presets / Pricing**: Refresh bundled model templates, model capabilities and pricing seeds against upstream. Existing custom prices are preserved; historical built-in prices are repaired only when they still match known defaults. Includes [#548](https://github.com/SaladDay/cc-switch-cli/pull/548).

## Fixed

- **Database / Compatibility**: Support upstream database schemas 23 through 26 for local startup and WebDAV/S3 restore, including snapshots from CC Switch desktop v4.0.33. Preserve upstream MCP/Skills enablement flags and session parser state through migrations, edits and sync round-trips. Includes [#549](https://github.com/SaladDay/cc-switch-cli/pull/549), fixing [#553](https://github.com/SaladDay/cc-switch-cli/issues/553) and addressing [#564](https://github.com/SaladDay/cc-switch-cli/issues/564).
- **WebDAV / Skills**: Preserve each file symlink's own name in skills archives, avoiding duplicate ZIP entries such as `CLAUDE.md -> AGENTS.md`. Directory cycle detection and outside-root restrictions remain intact. Includes [#559](https://github.com/SaladDay/cc-switch-cli/pull/559).
- **TUI / Terminal Hangup**: Exit the Unix TUI when its terminal disconnects, preventing an input polling loop from consuming a CPU core. Normal connected-terminal exits still restore terminal state. Includes [#558](https://github.com/SaladDay/cc-switch-cli/pull/558), fixing [#555](https://github.com/SaladDay/cc-switch-cli/issues/555).
- **Windows / Sessions**: Release child lock handles before publishing or retiring session snapshot directories, fixing `Access is denied (os error 5)` while preserving reader protection. Includes [#552](https://github.com/SaladDay/cc-switch-cli/pull/552), fixing [#542](https://github.com/SaladDay/cc-switch-cli/issues/542).
- **Claude / Proxy Authentication**: Use `ANTHROPIC_AUTH_TOKEN` for ordinary proxy-route placeholders and clear stale `ANTHROPIC_API_KEY` values, avoiding custom-key confirmation and conflicting credential warnings. Includes [#556](https://github.com/SaladDay/cc-switch-cli/pull/556), fixing [#554](https://github.com/SaladDay/cc-switch-cli/issues/554).
- **Proxy / Responses**: Emit `response.incomplete` for incomplete converted Codex responses and retain their usage and Chat history, so truncated turns are not reported as successful completions. Includes [#551](https://github.com/SaladDay/cc-switch-cli/pull/551), fixing [#546](https://github.com/SaladDay/cc-switch-cli/issues/546).
- **Proxy / Prompt Caching**: Keep mid-conversation system messages in their original positions during Anthropic-to-Chat conversion, preserving stable prompt prefixes across turns. Includes [#527](https://github.com/SaladDay/cc-switch-cli/pull/527).
- **Codex / Configuration**: Preserve explicit authentication settings and existing bearer credentials when editing provider forms. Omit the unsupported MCP `type` field from generated Codex TOML. Includes [#535](https://github.com/SaladDay/cc-switch-cli/pull/535) and [#512](https://github.com/SaladDay/cc-switch-cli/pull/512), addressing [#532](https://github.com/SaladDay/cc-switch-cli/issues/532) and [#496](https://github.com/SaladDay/cc-switch-cli/issues/496).
- **Codex OAuth / Quotas**: Use the bound account's native quota query for managed OAuth providers and hide the conflicting generic usage-template control in the Claude provider form. Existing automatic and manual refresh behavior is preserved. Includes [#534](https://github.com/SaladDay/cc-switch-cli/pull/534), fixing [#533](https://github.com/SaladDay/cc-switch-cli/issues/533).

## Upgrade notes

- Upgrade all CLI devices and containers before sharing a schema-26 database. CLI v5.11.3 and earlier cannot open it. Existing pre-migration backups remain in place; databases newer than schema 26, including upstream development schema 27, are still rejected.
- Database compatibility does not add CLI management for Oh My Pi, DeepSeek Harness, GitHub Copilot CLI or WorkBuddy.
- Managed ChatGPT accounts are not supported by isolated launches (`start`, TUI temporary launch or `--shared-sessions`). Switch to the bound official provider first, then run `codex`.
- Claude global settings should be edited through the complete configuration editor. Codex and Gemini common-snippet behavior is unchanged. Incomplete Codex responses can now surface a truncation or refusal error instead of silently completing.
- Run `cc-switch update`, or use `brew upgrade cc-switch-cli` for Homebrew installations once the formula is updated.
