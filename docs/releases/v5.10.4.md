# CC Switch CLI v5.10.4

v5.10.4 adds first-class Pi support and restores database compatibility with CC-Switch Desktop v3.20.1. It also adds upstream provider presets and OpenCode Go subscription queries, while fixing live provider projection and stale session views.

## Highlights

- Manage Pi providers, prompts, MCP servers, Skills, sessions, usage, launch behavior, and app visibility through the CLI and TUI.
- Use Pi presets plus selected upstream Claude and Codex presets for DeepSeek, Zhipu GLM, ModelScope, MiniMax, Xiaomi MiMo, OpenCode Go, and OpenRouter.
- Query OpenCode Go subscription usage through the existing usage interface.
- Share database snapshots with Desktop v3.20.1 using schema v18 and its Claude byte-cursor and tail-fingerprint format.
- Convert existing v17 line cursors without replaying historical usage, including an already-counted final line without a trailing newline.
- Keep validation and scanning on the same file handle so a concurrent path replacement cannot trigger a historical replay.
- Refresh the Sessions view on entry and keep active-provider edits projected to live configuration.

## Upgrade

The database migrates from schema v17 to v18 after creating the normal pre-migration backup. Devices sharing snapshots through WebDAV or S3 should all upgrade before syncing a v18 database because older releases reject newer schemas.

Existing Claude line cursors convert on the next changed-file scan. Truncated or rewritten files are pinned at their current end instead of being replayed, which avoids double-counting usage whose detail rows have already been rolled up and pruned.

Built-in updater:

```bash
cc-switch update
```

Homebrew:

```bash
brew upgrade cc-switch-cli
```

macOS/Linux installer:

```bash
curl -fsSL https://github.com/SaladDay/cc-switch-cli/releases/latest/download/install.sh | bash
```
